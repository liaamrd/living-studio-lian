# 2026-11-09

## Living Studio（p5.js 网格交互作品）

- `index.html`：库引用全部改为 CDN —— p5 1.9.4 (`p5@1.9.4/lib/p5.min.js`)、p5.sound 1.9.4 (`p5@1.9.4/lib/addons/p5.sound.min.js`)、ml5 0.12.2 (`ml5@0.12.2/dist/ml5.min.js`)，顺序 p5 → p5.sound → ml5 → sketch.js。本地 `p5.js` / `p5.sound.min.js` 已不再被引用。
- `sketch.js`：保留原「proximity stretch」逻辑（DEFAULTS / buildGrid / draw / keyPressed），新增 ml5 音频分类层：
  - `MODEL_URL = 'https://teachablemachine.withgoogle.com/models/gPa2FZdHa/model.json'`
  - 模型实际只有 3 类：`Background Noise` / `Clap` / `Voice`（softmax units=3，metadata.json wordLabels 确认）；`Tap` 映射保留待未来换模型。
  - `THRESHOLD = 0.85`，低于阈值为「中性」→ `soundTarget = null`，保持现状不回默认（避免抖动）。
  - `LABEL_MAP`：Clap(470/3.40/3.40)、Voice(330/2.00/1.50)、Tap(190/1.55/2.80)、Background(260/2.20/2.00)。
  - `applySoundRules()` 在 draw 开头用 `lerp(..., SOUND_SMOOTH=0.06)` 平滑推进 radius/maxStretch/ease。
  - `normalizeLabel()` 支持大小写/空格/中英别名与包含匹配。
  - HUD 加 label + confidence(百分比) + 置信度条(带 0.85 刻度)，面板宽 300；`m` 键静音切换；手动调参时自动脱离声音接管。
- 注意：麦克风需要 localhost 或 https，`file://` 下 getUserMedia 会失败。

## 升级（23:00 之后）：手动开麦 + 声音染色 + 映射表 HUD

- 麦克风改为**手动开启**：`micOn = false` 初始；`toggleMic()` 绑定 M 键，首次按 M 才调用 `classifier.classify(gotResult)`（浏览器要求用户手势）。`gotResult` 开头 `if (!micOn) return` 忽略结果；关麦时 `setNeutral` 清目标。`setup()` 不再自动开麦，`onModelReady` 只在 `micOn` 为真时补启动。
- 颜色：新增 `PALETTES = { clap:15/90/100, voice:280/80/100, tap:140/80/100 }`，Background 无颜色 = 保留原版 `lerp(25,205,nd)` 冷暖渐变。全局 `palette = {h,s,b,w}`，`updatePalette()` 每帧 lerp（`COLOR_SMOOTH=0.08`，w 0→1）。染色在 draw 循环里按 `m = palette.w * pow(t, COLOR_REACH=0.6)` 与原基线色混合，`t>0` 才生效。新增 `lerpHue()` 走最短弧。
- HUD 重写为按行着色（`rows.push({t,c,sz})` + `applyRowColor()`）：参数区 / 麦克风状态（关麦时红字 `Press 'M' to enable Microphone.`）/ label+confidence / `[ Sound Mapping ]` 三行彩色映射表 / 置信度条。PANEL_W 320。
- 已验证（node vm 模拟）：关麦忽略结果、M 开麦置位、Clap 60 帧后 palette 收敛到 15.1/89.9/100 且中心格 fill≈(15.95, 89.16, 99.71)、Background 时 w→0.007 回落渐变、voice 小写别名命中、0.70 置信度判中性。
